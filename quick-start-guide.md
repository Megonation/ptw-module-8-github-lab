# Request Technical Support

Use the support portal to report a technology problem or ask a support-related question.

## Before you begin

Have the following information ready:

- A brief description of the problem
- The name of the application or device involved
- Any error message you received
- Your location and preferred contact information
- A screenshot, if one would help explain the problem

## Submit a request

1. Open the support portal and sign in with your employee account.
2. Select the category that seems closest to your problem.
3. Enter a short summary in the **Subject** field.
4. Describe what happened, what you were trying to do, and any steps you already tried.
5. Add your location and contact information.
6. Attach a screenshot if it provides useful information.
7. Review the request and select **Submit**.

## Check your request

To check the status of a request, sign in to the support portal and open **My Requests**. If you have more information to add, open the existing request instead of submitting a duplicate.

## Important

If the problem is urgent, mark the request as urgent before submitting it. An urgent request still follows the regular support process; marking it urgent helps the support team understand its priority.
